## Goal

Turn the localhost UI from a single board into a small **dashboard** with three tabs — **Tasks**, **Changelog**, **Contributors**. Add a settings page, support archiving tasks, and attribute work to people via `git log`.

## What was delivered

### Tabs

- **Tasks** — the existing board. New: settings gear, archive toggle, sort dropdown, saved filters.
- **Changelog** — vertical timeline of every state change. Newest first. Filterable by kind, task, author.
- **Contributors** — git-log-derived contributors with task attribution. Expand a contributor to see their tasks and last 10 events.

### Full changelog (`kanban/changelog.ts`)

Append-only `.openkan/changelog.jsonl` — one event per line. Every mutating API records an event.

```ts
interface ChangelogEvent {
  id: string;            // chg-xxxxxxxx
  ts: string;
  kind: "task.created" | "task.updated" | "task.moved" | "task.deleted"
      | "task.archived" | "task.restored" | "task.commented"
      | "agent.started" | "agent.ended" | "agent.progress"
      | "git.commit-attributed" | "settings.changed" | "kanban.organized" | …;
  taskId?: string;
  author: string;        // git user.name, "agent:<name>", "user", "system"
  summary: string;
  payload: Record<string, unknown>;
}
```

### Git attribution (`kanban/git.ts`)

Pure module. `git log` parsing, `git config user.name/email`.

- `listContributors(root, opts)` → `Array<{name, email, commits, firstSeen, lastSeen}>`
- `listCommits(root, opts)` → commit list
- `attributeCommitsToTasks(root, tasks, opts)` → `Map<taskId, commits[]>` by file path overlap
- `currentUser(root)` → `{name, email}`

### Archive

- `Task.archived: boolean` (default false)
- `POST /api/tasks/:id/archive` and `/restore`
- `GET /api/tasks-index?includeArchived=true` to include archived
- MDX frontmatter includes `archived: <bool>`

### Settings modal

- Triggered by gear icon in topbar
- Project: port, host, default agent/model, default column, auto-archive days
- Personal: name, email, theme (dark/light/system)

### Improved drag-and-drop

- Custom ghost card (semi-transparent clone, follows cursor)
- Drop indicator line at insertion point
- Multi-card drag (Ctrl/Cmd-click to select, badge shows count)
- Invalid-drop shake animation

## Endpoints added
