# M8 — Inline comments on rendered MDX

> **Category:** `task` · **Priority:** ➡️ normal · **Effort:** —
> **Tags:** `task` `m8` `shipped`

User clicks any block on a rendered MDX to leave a comment anchored to that block. Comments persist to tasks/<id>/comments.json with the source line and content-hash block id. The agent reads the file and sees exactly which block the user was reacting to.
