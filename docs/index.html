A kanban board that both you and Claude Code read and write.

Tasks, goals, agent activity, and decision history — stored as plain files inside your repository. A local dashboard on 127.0.0.1:7777. A control plane your coding agent already understands. No account, no hosted service, no telemetry.

Install

$ npm install -g @polderlabs/openkan
$ cd /path/to/your/project
$ ok init
$ ok start
# dashboard opens at http://127.0.0.1:7777/

What you get

Five-column board

Backlog, To Do, In Progress, Review, Done. Drag-and-drop, keyboard shortcuts, right-click menus. Subtasks and archived items handled out of the way.

Tasks are plain files

Each task lives at .ok/tasks/<id>/task.mdx. Frontmatter drives the dashboard. You can read, edit, and diff them in any tool — your editor, your git history, your editor's quick-open.

Claude Code native

Installs a Claude Code agent and skill so the assistant can list, claim, comment, and move tasks without bespoke wiring. Ask Claude to "pick up the next review item" — it just works.

Chat sidebar with tabs

An embedded chat panel beside the board. Discuss a task, attach a screenshot, link a session. Tabs keep multiple conversations open while you work.

Local-only, no telemetry

Binds to 127.0.0.1. Nothing leaves your machine. Drop the project in a private network and the dashboard keeps working. Audit-friendly by construction.

Live preview, source links

Task MDX renders inline TSX previews. Source drift is detected automatically: the dashboard flags tasks whose origin file has changed and offers re-derive.

How it fits together

  1. 1

    Install once

    npm install -g @polderlabs/openkan ships the CLI, the local server, the Claude Code agent, and the dashboard's static assets.

  2. 2

    Initialize the project

    ok init creates .ok/ in your repo with a config file, an index, and an empty tasks directory. Safe to run twice.

  3. 3

    Start the dashboard

    ok start binds the server on 127.0.0.1:7777 and broadcasts board changes over Server-Sent Events. Closing the terminal stops it.

  4. 4

    Use the dashboard and the agent

    Drag a card in the UI, or have Claude Code pick it up. Both paths write the same MDX. git log shows your history and the agent's history, side by side.

"The .ok/ folder is the source of truth. The dashboard, the CLI, and Claude Code are three views over the same plain files."
